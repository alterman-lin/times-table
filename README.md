# times-table｜九九乘法大冒險

一個給國小學生練習九九乘法的網頁小遊戲。純前端、零建置、零伺服器依賴，
下載後雙擊 `index.html` 就能玩，也可以直接部署到任何靜態網頁空間
（GitHub Pages、Netlify、學校內部網站…）。

## 遊戲玩法

1. **選擇故事**：一開始先選一條故事線——「甜心少女」（賺金幣、逛商店打
   扮角色）或「改裝小車手」（每過一關自動把愛車修得更帥）。
2. **建立角色**：依所選故事線，從 3 位少女或 3 位男孩中選一位當自己的
   化身。
3. **玩法說明**：選完角色後會看到一頁極簡的圖示說明，讓玩家知道「答對
   題目 → 過關 → 拿到獎勵」的整體節奏，才進入正式關卡。
4. **六個關卡**：難度漸進，是非題 → 選擇題 → 輸入題，各跑一輪不限時、
   再跑一輪限時版，共 6 關，每關 10 題、答對 7 題以上算過關。兩條故事線
   共用同一套題目引擎與過關門檻，差別只在美術主題與獎勵機制。
5. **獎勵機制（依故事線二選一）**：
   - **甜心少女**：過關領金幣，到商店購買衣服／裙子／褲子／包包／飾品／
     鞋子六個部位的服裝（每個部位各有 3 款可選），即時換裝、可退貨。
   - **改裝小車手**：沒有金幣與商店，車子會依「已過幾關」自動從故障老爺
     車一路修到全新跑車（共 7 個外觀階段）；過第 4、5 關解鎖後可自選烤漆
     顏色（3 色），並能隨時到「改裝車庫」免費重新選色。
6. **失敗與結局**：某一關沒過可以選擇重新挑戰或結束本局（角色／愛車會
   變成落魄灰階樣）；六關全破會看到專屬慶祝結局（少女線是完整裝扮＋兔子
   小熊入鏡，小車手線是全新跑車登場）。結局畫面也能直接返回商店／車庫
   繼續打扮或改色，不會因為看過結局就失去進度，只有主動按「重新開始」
   才會真的重置。

題目只會出現 2～9 的乘法（不考 ×1，練習價值較低），每次進關卡都會重新
隨機出題、不重複。

## 專案結構

```
index.html          遊戲主頁面（選故事／建立角色／玩法說明／關卡地圖／
                     作答／結算／商店／改裝車庫／結局，全部用 <section>
                     切換顯示）
css/style.css        樣式；用 CSS 變數做主題切換，兩條故事線各自一套
                     配色（少女：粉色系格紋，小車手：藍灰色系格紋）
js/
  questions.js        九九乘法題目產生器
  storage.js          localStorage 存讀，支援多玩家、記錄故事線與進度
  shop.js             商店品項資料（六個部位，各 3 款服裝）
  character.js        少女角色分層渲染（換裝疊圖、頭像裁切）
  car.js              男孩愛車渲染（7 個改裝階段、3 色烤漆、頭像裁切）
  game.js             遊戲狀態機（關卡、計分、依故事線分岔的獎勵畫面、
                       結局）
assets/
  raw/                 Gemini 產生的原始插畫
  processed/           去背／萃取後的高解析度素材
  final/               縮小壓縮後、實際遊戲使用的素材
tools/
  bg_remove.py         去背工具（保留角色本身、去除背景連通區塊）
  extract_layer.py     用「基準圖 vs 換裝後的圖」做像素差異比對，萃取出
                        單一服裝／配件的透明圖層（商店品項用這個）
  finalize_asset.py    縮圖＋調色盤壓縮，產出遊戲用的最終素材
doc/                    美術風格與畫面設計稿（Claude Design Components 畫布）
```

## 本地開發

不需要任何建置工具，用任何靜態伺服器打開專案根目錄即可，例如：

```bash
python -m http.server 8935
```

再開瀏覽器連到 `http://localhost:8935`。

## 美術資產處理流程

依素材種類分成兩套做法，最終都會落到 `assets/final/`（遊戲實際載入的
資料夾）：

- **服裝／配件（差異萃取法）**：準備一張「未換裝」的基準參考圖（例如
  `base_girl_happy.png`），請 Gemini 在同一張圖上只加一項服裝或配件、
  其餘姿勢／比例／畫風完全不變，輸出存到 `assets/raw/`；再用
  `tools/extract_layer.py <基準圖> <換裝後的圖> <輸出路徑>` 比對兩張圖的
  像素差異，只萃取出新增的那件衣物存到 `assets/processed/`，最後用
  `tools/finalize_asset.py` 縮圖壓縮到 `assets/final/`。
- **整張角色／載具插畫（去背法）**：像少女的三種表情立繪、男孩三個系列
  的 7 階段愛車圖，本身就是整張要顯示的圖（不是疊加圖層），Gemini 產出
  後存到 `assets/raw/`，用 `tools/bg_remove.py` 去除背景存到
  `assets/processed/`，再用 `tools/finalize_asset.py` 縮圖壓縮到
  `assets/final/`。同一個角色／載具的系列圖會用「反覆編輯同一張圖、每次
  只要求一個改動」的方式請 Gemini 產生，確保整組圖姿勢與鏡頭一致。
